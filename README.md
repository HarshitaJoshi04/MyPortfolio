# Personal Portfolio Website

A responsive portfolio website built to showcase my technical skills, featured projects, and contact information.

🔗 **Live Demo:** [https://harshita-portfolio-88.vercel.app/](https://harshita-portfolio-88.vercel.app/)

## Sections Included

- **Skills** – A showcase of my technical skills and tools I work with.
- **Projects** – Highlights of my featured projects with links to live demos and source code.
- **Contact** – A way for visitors/recruiters to get in touch with me.

## Tech Stack

- **React.js** – Frontend library for building the UI
- **Tailwind CSS** – Utility-first CSS framework for styling
- **JavaScript** – Core scripting language
- **GSAP** – For smooth, interactive animations

## Features

- Fully responsive design (mobile, tablet, and desktop friendly)
- Clean and modern UI
- Smooth animations for an engaging user experience
- Easy navigation between Skills, Projects, and Contact sections

## Getting Started

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/HarshitaJoshi04/MyPortfolio.git

# Navigate into the project directory
cd MyPortfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```
